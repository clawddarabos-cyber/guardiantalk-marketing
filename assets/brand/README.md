# GuardianTalk developer brand handoff

## Approved design
Use `GuardianTalk_Approved_Reference_Tight.png` as the **visual source of truth** for the approved centered, tightly cropped primary logo. The gold rear chat bubble must remain a complete continuous bubble, partially occluded by the teal front bubble.

## Assets
- Primary logo: `GuardianTalk_Primary_Dark.svg` and PNG.
- Transparent and light-background variants provided.
- Bordered app icon: `GuardianTalk_App_Icon_Bordered.svg` and PNG exports.
- Favicon: `favicon.ico`, 16px and 32px PNG.
- CSS/JSON tokens provided for developers.

## Implementation
Use SVG for responsive web logos; use the bordered square PNG for app icon / PWA and validate platform-specific requirements. Keep clear space around the logo, preserve proportions, and do not cut off the gold chat bubble.

**Important:** SVG files are editable vector recreations of the approved raster concept, not exact tracings. The wordmark uses a font stack and can render differently on systems without the same font. Review the rendered SVG against the approved reference before shipping. Do not treat these as legally cleared trademarks.
